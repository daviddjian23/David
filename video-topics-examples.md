## 💡 Comment Utiliser Ces Sujets

### Dans le Workflow n8n

Modifiez le nœud "Schedule Trigger" :

```json
{
  "video_topic": "5 astuces pour être productif dès le matin",
  "style": "professional",
  "gender": "female",
  "age_range": "25-35"
}
```

### Rotation Automatique des Sujets

Créez plusieurs workflows ou utilisez un nœud de choix aléatoire :

```javascript
const topics = [
  "5 astuces pour être productif",
  "Comment gérer son temps efficacement",
  "La méthode Pomodoro expliquée",
  // ... ajoutez tous vos sujets
];

const randomTopic = topics[Math.floor(Math.random() * topics.length)];

return { video_topic: randomTopic };
```

### Planification Thématique

Organisez vos sujets par jour de la semaine :

- **Lundi** : Motivation & Développement Personnel
- **Mardi** : Productivité & Business
- **Mercredi** : Tech & Innovation
- **Jeudi** : Santé & Bien-être
- **Vendredi** : Lifestyle & Loisirs
- **Samedi** : DIY & Créativité
- **Dimanche** : Culture & Éducation

### Adapter les Sujets à Votre Audience

1. **Analysez les performances** : Quels sujets génèrent le plus d'engagement ?
2. **Testez des variations** : Reformulez les titres qui marchent
3. **Suivez les tendances** : Adaptez les sujets aux actualités
4. **Niche down** : Spécialisez-vous progressivement

## 🎯 Formules de Titres qui Marchent

- **Liste** : "5 façons de...", "10 astuces pour...", "3 erreurs à éviter..."
- **Question** : "Comment... ?", "Pourquoi... ?", "Combien... ?"
- **Urgence** : "Arrêtez de...", "Commencez dès aujourd'hui..."
- **Curiosité** : "Le secret de...", "Ce que personne ne dit sur..."
- **Transformation** : "De... à... en X jours", "Comment passer de... à..."
- **Comparaison** : "X vs Y : lequel choisir ?", "... ou ... ?"
- **Guide** : "Le guide complet de...", "... pour débutants"
- **Erreur** : "Les X erreurs de...", "Pourquoi vous échouez à..."
